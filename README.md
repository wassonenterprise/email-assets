# Email assets

Public images for Wasson Enterprise email signatures.

`we-fulllogo-orange-120.png` is 120 by 52 pixels. That pixel size is the display size. Apple Mail draws a signature image at the file's real size and ignores the width and height in the HTML. Do not replace this file with the full 3510 by 1514 logo.

The website header stays on the full file: https://wassonenterprise.com/wp-content/uploads/2022/12/WE_FULLLOGO_ORANGE_RGB.png
